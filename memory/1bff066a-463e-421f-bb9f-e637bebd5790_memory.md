## Memory Block

**工作背景**
BOSS是深圳米林客华东分公司负责人，常驻合肥，负责安徽、江苏、浙江三省业务团队管理。团队约10名业务员，分三组运作：安徽组（1组长+3业务员，计划再补1人作前线补充）、江苏组（1组长+1老业务员+1新人+招聘中）、浙江组（1强+1弱+1不服从的老业务员，浙江组为当前最大管理风险点）。核心业务定位为30间房以下的中小型酒店与民宿（大酒店仅机会性跟进）提供一站式供应链服务，主推智能客控、智能门锁、电子门牌、TCL/长虹电视、卫浴、灯具、床垫等产品。销售漏斗策略以智能客控+天猫精灵作为入门引流款，门锁/门牌绑定客控合同成交，电视/卫浴/床垫/灯具作为后续利润型复购品。

**个人背景**
BOSS沟通风格直接高效，偏好少绕弯、给方案式的输出方式，要求AI产出简洁、结构化、可直接落地的内容（表格/议程/话术/行动项等）。日常习惯称呼AI为"磨人精"（曾用名"小天"），自称"BOSS"，全中文沟通。BOSS倾向通过对话迭代校验假设，会基于真实市场反馈纠正AI判断（如智能客控已从利润款转为引流款）。开会时偏好清晰议程、明确责任人与截止日期，善于将人员问题纳入整体能力体系框架中处理。

**当前关注**
BOSS聚焦三大核心痛点的系统性解法：一是项目跟进后客户迟迟不推动签约，导致成单周期拉长；二是客户常以"不着急"为由拖延决策，缺乏破局抓手；三是业务员日报、周计划流于形式，团队执行力薄弱（头部4-5单/月，尾部仅1-2单/月，差距明显）。需针对这些场景输出可复用的诊断工具、跟进SOP、逼单话术与执行管控方案，并兼顾浙江组人员管理风险的处理。

**近期动态**
- 已明确销售漏斗分层策略：智能客控+天猫精灵（引流款）→ 门锁/门牌（绑定成交）→ 电视/卫浴/床垫/灯具（利润复购）。
- 团队产能分布清晰：10人团队，头部4-5单/月，尾部1-2单/月，需针对性赋能提升整体产出；计划为安徽组再补1名前线业务员填补民宿客群缺口。
- 目标客户画像锁定：30间房以下中小酒店与民宿，大酒店仅机会性跟进，不作为核心投入方向。
- BOSS已在对话中修正AI对智能客控的定位判断——明确其为低毛利引流产品而非利润驱动款，体现以市场实况校准策略的工作方式。
- 浙江组人员配置（1强+1弱+1不服从老业务）被识别为当前最大管理风险点，需纳入后续能力体系与人员调整方案。
